# Student Management System

A command-line Python application to manage student records, with user login and input validation.

## Features
- User authentication (login/register)
- Add, view, update and delete student records
- Input validation for student data
- Data stored in CSV files

## Tech Used
- Python 3
- CSV file storage

## Project Structure
- `main.py` – entry point of the program
- `auth.py` – login and user handling
- `student.py` – student record operations
- `validtion.py` – input validation helpers

## How to Run
1. Clone the repo:
```
   git clone https://github.com/somaygahlot09/Student-management-system.git
```
2. Go into the folder:
```
   cd Student-management-system
```
3. Run the program:
```
   python main.py
```
